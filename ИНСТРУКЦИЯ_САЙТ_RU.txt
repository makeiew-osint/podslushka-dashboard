ИНСТРУКЦИЯ ПО САЙТУ PODSLUSHKA DB

1. Запуск

Откройте папку проекта и запустите launcher-файл. Если launcher отсутствует,
выполните:

  python -m pip install -r requirements.txt
  python db_viewer.py

Локальная панель обычно открывается по адресу http://127.0.0.1:8765/.

2. Вход

Введите логин, пароль и код 2FA, если он включён. Новая регистрация сначала
попадает владельцу на одобрение. После входа доступны только разделы,
разрешённые вашей ролью.

3. Роли

Owner управляет проектами, ботами, доступом и настройками.
Admin управляет назначенными ботами и модерацией.
Moderator работает с заявками и пользователями.
Read-only просматривает данные без управляющих действий.

4. Проекты и боты

В разделе «Боты» владелец создаёт проект, указывает школу/город и подключает
Telegram-бота. Токен не показывается в интерфейсе и хранится зашифрованным.
Бот должен быть администратором канала с правом публикации сообщений.

5. AI

AI-автопубликация включается отдельно для каждого бота или основного legacy-бота.
Автопубликация выполняется только при безопасном решении AI и достаточном
пороге уверенности. Сомнительные заявки остаются на ручной модерации.

6. Уведомления

В Telegram-канал отправляются только важные сообщения: технические работы,
восстановление сайта, запуск/остановка worker и критические ошибки. Обычные
входы, логи и действия панели не публикуются.

Для режима технических работ установите:

  SITE_MAINTENANCE_MODE=true

После запуска панели верните значение false, чтобы отправить сообщение
«Сайт снова работает».

7. Безопасность

Не публикуйте BOT_TOKEN, MULTIBOT_ENCRYPTION_KEY, OWNER_PASSWORD и секреты
OAuth. Для смены пароля используйте раздел «Профиль».
