## О сервисе

Podslushka DB — готовая закрытая рабочая панель для владельцев и модераторов
Telegram-сообществ. В одном интерфейсе доступны:

- очередь модерации, жалобы, публикация и аудит действий;
- управление подключёнными Telegram-ботами;
- поиск публичных username по открытым источникам;
- история проверок, сравнение результатов и экспорт отчётов;
- адаптивный интерфейс для компьютера и телефона.

## Как пользоваться

1. Откройте **[podslushka-dashboard.onrender.com](https://podslushka-dashboard.onrender.com/)**.

через этот репозиторий не предусмотрены. Если сайт временно недоступен,
дождитесь окончания технических работ или обратитесь к владельцу сервиса.

## Важно

OSINT-раздел проверяет только открытые веб-источники и не подтверждает личность
человека. Используйте сервис законно и только для разрешённых задач.
