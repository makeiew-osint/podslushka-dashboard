# Podslushka DB

Защищённая панель управления Telegram-ботами, заявками и модерацией. Проект
поддерживает локальный запуск на Windows, деплой на Render, SQLite или
PostgreSQL, несколько Telegram-ботов и отдельные права доступа.

## Возможности

- Dashboard с обзором пользователей, заявок, публикаций и жалоб.
- Роли `owner`, `admin`, `moderator`, `read-only` и `user`.
- Проекты и несколько подключённых Telegram-ботов.
- Изоляция данных между ботами через `bot_id`.
- Зашифрованное хранение токенов подключённых ботов.
- Ручная модерация и безопасная AI-автомодерация с порогом уверенности.
- Публикация одобренных материалов в Telegram-канал.
- Мониторинг worker-процессов и состояния базы.
- Owner-режим проверки администратора с заметным баннером и журналом действий.
- Резервное копирование, CSV-экспорт и журнал изменений.
- Тёмный интерфейс с CSS-3D: сферы, кубы, орбиты, частицы, подсветка,
  hover-эффекты и анимированные карточки.
- Независимый GitHub Actions-мониторинг сайта с уведомлениями о недоступности
  и восстановлении.

## Структура

| Файл | Назначение |
| --- | --- |
| `db_viewer.py` | HTTP-панель, авторизация, HTML/CSS/JS, API и supervisor |
| `bot.py` | Telegram handlers, заявки, модерация и публикация |
| `db.py` | Асинхронный слой базы данных |
| `config.py` | Конфигурация окружения |

## Локальный запуск Windows

1. Откройте PowerShell в папке проекта.
2. Создайте виртуальное окружение и установите зависимости:

   ```powershell
   python -m venv venv
   .\venv\Scripts\python.exe -m pip install -r requirements.txt
   ```

3. Создайте `.env` и заполните необходимые переменные.
4. Запустите:

   ```powershell
   .\venv\Scripts\python.exe db_viewer.py
   ```

   Или используйте `run.bat`.

Панель по умолчанию доступна на `http://127.0.0.1:8765/`.

## Основные переменные окружения

```env
BOT_TOKEN=токен_бота
ADMIN_IDS=123456789,987654321
CHANNEL_ID=@имя_канала
OWNER_USERNAME=owner
OWNER_PASSWORD=небезопасный_пример_заменить
DATABASE_URL=postgresql://...
MULTIBOT_ENCRYPTION_KEY=ключ_fernet
GEMINI_API_KEY=ключ_AI
TELEGRAM_UPDATES_CHAT_ID=-100...
SITE_MAINTENANCE_MODE=false
```

Не добавляйте `.env`, токены, пароли и базы с реальными данными в Git.

## Telegram-канал

Бота нужно добавить администратором канала с правом публикации сообщений.
Для публикации используется `CHANNEL_ID` в формате `@channel_username` или
числовой ID `-100...`. Для системных сообщений задаётся отдельный
`TELEGRAM_UPDATES_CHAT_ID`.

## AI-модерация

AI включается отдельно для managed-бота. Автопубликация разрешена только при
решении `publish=true` и достижении настроенного порога уверенности. Если AI
недоступен или ответ невалиден, заявка остаётся на ручной проверке.

## Проверка аккаунта администратора

Owner открывает раздел «Владельцы» и нажимает «Войти для проверки». Пароль
администратора не используется. Режим явно показывается баннером, записывается
в журнал и блокирует опасные операции: смену пароля, токены, экспорт, backup,
создание ботов и изменение настроек. Для возврата нажмите «Завершить проверку».

## Мониторинг сайта

Workflow `Monitor Podslushka DB` запускается каждые пять минут независимо от
Render. В GitHub Actions добавьте Secrets:

```text
BOT_TOKEN
TELEGRAM_UPDATES_CHAT_ID
```

Опционально добавьте Repository Variable `SITE_URL`. При первом успешном
запуске монитор только сохраняет baseline. Сообщение о техработах отправляется
при переходе `online -> offline`, а сообщение о восстановлении — при переходе
`offline -> online`.
