PODSLUSHKA DB TELEGRAM BOT GUIDE

1. Configuration

Create a bot with @BotFather and keep its token in BOT_TOKEN, or connect it
through the website «Bots» section.

Set:

  BOT_TOKEN — Telegram bot token
  ADMIN_IDS — comma-separated Telegram administrator IDs
  CHANNEL_ID — channel @username or numeric -100... ID
  DATABASE_URL — PostgreSQL URL when PostgreSQL is used
  MULTIBOT_ENCRYPTION_KEY — encryption key for connected bot tokens

2. Channel permissions

Add the bot as a channel administrator and enable «Post messages». Without this
permission Telegram returns Forbidden and publishing cannot succeed.

3. Submissions

Users send messages to the bot. A submission is stored with pending status.
An administrator can approve or reject it. After approval, the bot publishes
the material to the configured channel.

4. AI moderation

AI checks text submissions. If the decision is not confident enough, the
submission remains in manual review. AI errors never auto-publish a submission.

5. Isolation

Each managed bot runs in a separate worker process. Users, submissions, media,
and publications are scoped by bot_id so one bot cannot access another bot's
data.

6. Diagnostics

Use «Monitoring» on the website to inspect worker state. The website sends
Telegram alerts for worker stops and critical errors. Tokens are never written
to logs.
